今日の問い


利益が増えた会社の株価は、上がるのか


会計情報は、投資家の役に立っているのでしょうか。

もし役に立っているなら、良い決算を出した会社の株価は上がるはずです。 この問いは、会計学の実証研究が最初に取り組んだ問いでもあります。

会計の存在意義に関わる問い。会計情報が株価と無関係なら、投資家にとって会計は不要ということになる。 「会計学の実証研究が最初に取り組んだ問い」は、第2部で紹介するボール＝ブラウン（1968年）のこと。ここでは名前は出さず、後で回収する。

予想してください（隣と2分）

ROE（自己資本利益率）が高い会社ほど、その年の株価リターンは高いでしょうか。

ROEと株価リターンの相関係数は、どれくらいだと思いますか。

① 0.3 以上（はっきりした正の関係）
② 0.1 〜 0.3 くらい（弱い正の関係）
③ 0 〜 0.1 くらい（ほぼ関係なし）
④ マイナス（ROEが高いほど株価は下がる）


  • 株価リターン：1年間で株価が何%上がったか（配当も含める）
  • 相関係数：2つの変数が一緒に動く度合い。-1 〜 1 の値をとる

挙手で集計する。①か②が多数派になるはず。「儲かっている会社の株は上がるに決まっている」という直感。 答えは③ほぼ0（このデータでは約 -0.01）。ここでは答えを言わない。第2部の答え合わせまで引っ張る。 少数派（③④を選んだ人）に理由を聞くと良い。「もう株価に織り込まれているから」と言える学生がいたら大きく褒める。 相関係数は第3回・第4回で名前だけ出ている。ここで改めて一言定義しておく。

第1部：データの結合

今日使う2つのデータ

library(tidyverse)
fin   <- read_csv("data/ch04_financial_data.csv")  # 財務データ（年次）
stock <- read_csv("data/ch05_stock_data.csv")      # 株価データ（月次）

fin：財務データ（7,920行）

列 意味
firm_ID, year 企業番号・年度
X 当期純利益
OA, FA 営業資産・金融資産
OL, FO 営業負債・金融負債

1社1年 ＝ 1行

stock：株価データ（95,040行）

列 意味
firm_ID, year, month 企業番号・年・月
stock_price 月末の株価（円）
DPS 1株あたり配当（円）
adjustment_coefficient 株式分割の調整係数

1社1年 ＝ 12行

テキスト付属の2つのCSVを data フォルダに置いておくこと（第4回の補足資料と同じ手順）。 財務データは金額の単位が百万円。株価は円、株式数は株。 いちばん大事なのは一番下の行。財務は1社1年1行、株価は1社1年12行。形が違う。 1515社、2015〜2020年のデータ。

まず、やってはいけない結合

bad <- fin |>
  left_join(stock, by = c("firm_ID", "year"))   # 企業番号と年度でつなぐ

nrow(fin)   # 結合前
[1] 7920
nrow(bad)   # 結合後
[1] 95040

行数が 12倍 に増えました。1社1年の財務データが、12か月分コピーされたのです。

エラーも警告も出ません。 このまま回帰すると、同じ会社を12回数えた結果になります。

left_join(x, y, by = ...) は、x の各行に、キーが一致する y の行をくっつける関数。 y 側に一致する行が12行あれば、x の1行は12行に増える。dplyr はこの「1対多」の結合を正常な操作とみなすので、警告を出さない。 問いかけ：「この bad で回帰したら何がおかしくなる？」 想定解：同じ観測を12回数えるので、サンプルが12倍に水増しされ、p値が不当に小さくなる。

正しい手順：形をそろえてから、つなぐ

結合の前に、両方を「1社1年 ＝ 1行」にそろえる。 これが結合のいちばん大事な約束です。

図の読み方：左上の月次データを、①月ごとのリターンにして、②年ごとにまとめる。これで下の財務データと同じ形になる。③そのうえで結合する。 これから3枚のスライドで①②③を順にコードにする。

① 月次リターンを計算する

r_{\text{月}} = \frac{\text{今月の株価} \times \text{調整係数} + \text{配当}}{\text{先月の株価}} - 1 

stock_m <- stock |>
  arrange(firm_ID, month_ID) |>          # 会社ごとに、月の順に並べる
  group_by(firm_ID) |>                   # 会社ごとに計算する
  mutate(ret = (stock_price * adjustment_coefficient + DPS) / lag(stock_price) - 1) |>
  ungroup()
  • lag() ＝ 1つ前の行の値（ここでは先月の株価）
  • group_by() があるので、別の会社の株価を先月として使わない
  • 調整係数：1株が1.2株に分割されたら1.2。分割で株価が下がった分を戻す
  • 配当も株主の取り分なので足す

株式分割：1株を複数株に分けること。株価は分割比率に応じて下がるが、株主の資産は減っていない。調整係数をかけて元に戻す。 例：分割前4,371円、分割後4,082円、調整係数1.2。調整しないと -6.6%、調整すると 4,082×1.2÷4,371-1 ≒ +12%。 問い：group_by を忘れるとどうなるか。想定解：会社1の最後の月の株価を、会社2の最初の月の「先月」として使ってしまう。 各社の最初の月は先月がないので ret は NA になる。

② 年ごとにまとめる（年次リターンと時価総額）

stock_y <- stock_m |>
  filter(!is.na(ret)) |>
  group_by(firm_ID, year) |>
  summarise(
    n_month = n(),                                              # 何か月分あるか
    R       = prod(1 + ret) - 1,                                # 年次リターン
    MV      = last(stock_price) * last(shares_outstanding) / 1e6, # 年末の時価総額（百万円）
    .groups = "drop"
  )
stock_y |> count(firm_ID, year) |> filter(n > 1)   # 検算：1社1年1行になったか
# A tibble: 0 × 3
# ℹ 3 variables: firm_ID <dbl>, year <dbl>, n <int>

prod(1 + ret) - 1 ＝ 月次リターンを掛け算でつなぐ（複利）。足し算ではありません。
最後の検算コードの結果が0行なら、「1社1年 ＝ 1行」になっています。

なぜ掛け算か：1月に+10%、2月に-10%なら、1.1×0.9=0.99で-1%。足し算だと0%になってしまう。 時価総額＝株価×発行済株式数。財務データと単位をそろえるため、100万で割って百万円にしている。 count(firm_ID, year) |> filter(n > 1) は、キーが重複している行だけを取り出す検算。結合の前に毎回やる。

③ つなぐ：結合の「約束」をコードに書く

df <- fin |>
  left_join(stock_y, by = c("firm_ID", "year"),
            relationship = "one-to-one")          # 1対1でなければエラーにする

nrow(fin); nrow(df)                                # 検算：行数は変わっていないか
[1] 7920
[1] 7920

relationship = "one-to-one" を書いておくと、さっきの12倍の事故が起きたとき、Rがエラーで止めてくれます。

関数 残る行
left_join(x, y) x の行は全部残る
inner_join(x, y) 両方にある行だけ
full_join(x, y) どちらかにある行全部

試しに stock（月次）のまま relationship = “one-to-one” で結合するとエラーになる。時間があれば実演する。 left_join は「左側（財務データ）を主役にする」結合。財務データにない会社の株価は捨てられ、株価がない会社はNAになる。 inner_join と使い分けられるとよいが、今日は left_join だけで十分。

分析に使う変数を作る

df <- df |>
  arrange(firm_ID, year) |>
  group_by(firm_ID) |>
  mutate(lag_MV = lag(MV), lag_X = lag(X), lag_BE = lag(OA + FA - OL - FO)) |>  # 前年の値
  ungroup() |>
  mutate(
    BE   = OA + FA - OL - FO,        # 自己資本 ＝ 資産 − 負債
    ROE  = X / BE,                   # 自己資本利益率
    EP   = X / lag_MV,               # 利益の水準（期首の時価総額で割る）
    dEP  = (X - lag_X) / lag_MV,     # 利益の変化（期首の時価総額で割る）
    size = log(lag_MV),              # 会社の規模（期首の時価総額の対数）
    up   = if_else(R > 0, 1, 0),     # 株価が上がった ＝ 1
    inc  = if_else(X > lag_X, 1, 0)  # 増益 ＝ 1
  ) |>
  filter(n_month == 12, !is.na(dEP))  # 12か月そろい、前年がある行だけ
nrow(df)
[1] 6405

期首：その年の始まり（＝前年の年末）。株価リターンは1年間の変化なので、それと比べる利益も「年の初めの時価総額」で割ってそろえる。これは第4回の「比率にする」処方箋そのもの。 EP は Earnings / Price の略。dEP は「利益の変化 ÷ 期首時価総額」。 各社の最初の年は前年がないので落ちる。7,920行 → 6,405行。落ちた1,515行は、ちょうど会社数と同じ。これも検算になる（1社につき最初の1年が落ちる）。

第2部：相関分析

答え合わせ：ROE と株価リターン

cor(df$R, df$ROE)
[1] -0.007005678

答えは ③ ほぼ 0 でした。

予想で①②を選んだ人が多かったはず。それが普通の直感。 図は見やすさのため表示範囲を絞っている（coord_cartesian は表示範囲を変えるだけで、データは捨てていない）。 直線はほぼ水平。ROE が高い会社も低い会社も、株価リターンはばらばら。

なぜ、ほぼ0なのか

ROE が高い会社は……

  • 去年も、おととしも、たぶん高かった
  • 投資家はそれを知っている
  • だから株価は、すでに高い

株価が動くのは……

みんなが知っていることでは、株価は動きません。

株価を動かすのは「予想外の変化」です。

だとすると、見るべきは利益の水準ではなく、利益の変化ではないでしょうか。

株価はみんなの予想をすでに織り込んでいる（効率的市場の考え方。名前は出さなくてよい）。 「ROEが高い」こと自体は去年からわかっているので、今年のリターンを生まない。今年のリターンを生むのは、予想より良かった・悪かったという「驚き」。 最も単純な驚きの代わりとして「去年より増えたか（利益の変化）」を使う。

利益の「変化」で見ると

df |> select(R, ROE, EP, dEP) |> cor() |> round(3)

R と dEP（利益の変化）の相関は 0.17。弱いけれど、はっきりプラスです。
cor() にデータフレームを渡すと、すべての組み合わせの相関をまとめて出します（相関行列）。

相関行列の読み方：対角線は自分自身との相関なので必ず1。左下と右上は同じ数字。 R の行（または列）だけ見ればよい。ROE はほぼ0、EP（利益の水準÷期首時価総額）は 0.13、dEP は 0.17。 EP と dEP の相関が 0.39 あることも覚えておく。第3部の重回帰で効いてくる。 問い：EP と ROE はどちらも「利益÷何か」なのに、なぜ R との相関が違うのか。想定解：EP の分母は期首の時価総額で、株価の情報が入っている。ROE の分母は帳簿上の自己資本。

相関係数の落とし穴：アンスコムの四重奏

4組とも、相関係数は 0.82、回帰直線も同じです（統計学者アンスコム、1973年）。
相関係数を出したら、必ず散布図も見る。 組3・組4は、たった1点が数字を決めています。

組1：ふつうの関係。組2：曲線の関係なのに直線を当てている。組3：外れ値1つが線を曲げている。組4：1点だけで線が決まっている。 第4回の上位5社の話と同じ構造。相関係数は「直線的な関係」しか測れず、外れ値に弱い。 外れ値に強い相関として順位相関（スピアマン）がある。cor(x, y, method = “spearman”)。このデータでは R と dEP で 0.19。

相関は、因果ではない

「増益 → 株価が上がる」？

  • 増益が株価を上げたのかもしれない
  • 景気が良い年は、利益も株価も両方上がるだけかもしれない
  • 株価が上がったから、利益が増えたのかもしれない

相関係数が言えるのは、
「一緒に動いている」ということだけです。

どちらが原因かは、相関係数からは言えません。

第三の要因（景気など）を入れて確かめる道具が、次の重回帰です。

第三の要因（交絡要因）の例として景気を挙げる。景気が良い年は利益も株価も同時に上がる。 逆の因果の例：株価が上がると資金調達しやすくなり、投資が増えて利益が増える、など。 重回帰は「他の要因を一定にしたら」を数字で言う道具。ただし重回帰でも因果は完全には言えない。それは後の回で扱う。

研究の裏話：1968年のボール＝ブラウン

  • ボールとブラウンは、米国企業の利益の増減と株価の動きを比べました
  • 結果：増益の会社は株価が上がり、減益の会社は下がる
  • 「会計の数字は投資家の役に立っている」ことを、データで示した最初の研究の1つです

今では実証会計学の出発点と呼ばれる論文です。

最初に投稿した学術誌では不採択だった、という話が知られています。
当たり前に見える問いを、データで確かめることに価値があったのです。

Ball, R. and P. Brown (1968) “An Empirical Evaluation of Accounting Income Numbers,” Journal of Accounting Research. 当時は「会計利益は恣意的に作られた数字で、意味がない」という批判が強かった。それにデータで反論した研究。 今日の分析は、この研究の考え方を、テキストのデータでなぞるもの。第4部のロジットとライブ分析で、増益・減益の比較をそのまま再現する。

第4回と同じ lm()。見る場所は3つ：傾き、p値、R²。 傾き 1.18 の読み方は次のスライド。

傾きをことばにする

傾き 1.18：期首時価総額の 1% にあたる分だけ利益が増えた会社は、株価リターンが平均で約 1.18%ポイント 高い。

p 値：dEP の行の Pr(>|t|) は 1.5e-41（ほぼ0）。0.05 よりずっと小さく、偶然とは考えにくい。

R^2 ＝ 0.028：株価リターンのばらつきのうち、利益の変化で説明できるのは 約3% だけ。


関係は確かにある。でも、株価の動きのほとんどは利益以外で決まっている。

dEP は「利益の変化÷期首時価総額」。0.01 は時価総額の1%分の増益。そのとき R は b1×0.01 だけ高い。R も比率なので「%ポイント」と言う。 R² が小さいのは失敗ではない。株価は金利、為替、業界ニュース、景気など無数の情報で動く。利益はその1つにすぎない。 研究の裏話：レブ（1989年）は、それまでの研究を総ざらいして「利益と株価の関係はあるが、R²は驚くほど小さい」とまとめた。会計学者にとっては耳の痛い結果だった。

重回帰：説明変数を増やす

R_i = \beta_0 + \beta_1 \, EP_i + \beta_2 \, dEP_i + \beta_3 \, size_i + u_i 

model2 <- lm(R ~ EP, data = df)
model3 <- lm(R ~ EP + dEP, data = df)          # + でつなぐだけ
model4 <- lm(R ~ EP + dEP + size, data = df)

書き方は単回帰と同じ。~ の右側に + で変数を足すだけです。

各係数は、「他の説明変数を一定にしたときの」その変数の効果を表します。

EP：利益の水準、dEP：利益の変化、size：規模（期首時価総額の対数）。 「他の説明変数を一定にしたとき」がこのスライドの一言。たとえば β2 は「同じ EP、同じ規模の会社どうしで比べたとき、dEP が高い会社はリターンがどれだけ高いか」。 summary() を4回見比べるのは大変なので、次のスライドで1つの表に並べる。

EP と dEP は相関しています（0.39）。

モデル (2) の EP は、dEP の効果まで背負っていたのです。dEP を入れると、その分が dEP に移ります。


単回帰の係数は、入れなかった変数の効果を混ぜてしまうことがあります。
重回帰は、それを「他を一定にして」切り分ける道具です。

利益の水準が高い会社は、利益が増えた会社であることが多い。だから EP だけで回帰すると、EP の係数には「増益の効果」も混ざる。 これを「欠落変数バイアス」と呼ぶ（名前は紹介だけ）。 問い：(4) で size の係数がマイナスなのはなぜか。想定解：このデータでは、期首に小さかった会社ほどリターンが高い。小型株ほどリターンが高いという「規模効果」として知られる現象と同じ向き。 研究の裏話：利益の水準と変化を両方入れるこの式は、イーストンとハリス（1991年）の論文で広まった形。

第4部：ロジットモデル

被説明変数が「はい／いいえ」のとき

これまで

  • 株価リターン 何%（連続した数）
  • 「リターンは平均でどれだけ高いか」

→ 回帰分析（lm()）

これから

  • 株価が 上がった（1）／上がらなかった（0）
  • 「上がる確率はどれだけ高いか」

→ ロジットモデル（glm()）


「倒産するか」「配当を出すか」「赤字になるか」「M&Aされるか」。
会計の実証研究には、はい／いいえで答える問いがたくさんあります。

0/1 の変数をダミー変数と呼ぶ。さきほど作った up（株価が上がった＝1）と inc（増益＝1）がダミー変数。 はい／いいえ型の問いの例を挙げて、ロジットが会計研究でよく使われることを伝える（倒産予測、配当の有無など）。

まず、表で比べる（ボール＝ブラウンの再現）

df |>
  group_by(inc) |>
  summarise(件数 = n(), 上がった割合 = mean(up))
# A tibble: 2 × 3
    inc  件数 上がった割合
  <dbl> <int>        <dbl>
1     0  2481        0.513
2     1  3924        0.636

減益の会社で株価が上がったのは 51.3%、増益の会社では 63.6%。
増益の会社のほうが、株価が上がる確率が 12.3%ポイント高い。

0/1 の変数の平均は「1の割合」になる。mean(up) は「上がった会社の割合」。 これが1968年のボール＝ブラウンと同じ比べ方。50年以上前の米国の発見が、このデータでも再現されている。

ロジットモデルで同じことをする

glm(..., family = binomial) がロジットモデル。lm() を glm() に替えて、family = binomial を足すだけです。
predict(..., type = "response") で確率に直すと、さっきの表と同じ数字が出てきます。

説明変数がダミー1つだけなら、ロジットの予測確率は表の割合とぴったり一致する。これでロジットが「確率のモデル」だと実感させる。 係数 0.506 は確率ではない。「対数オッズ」という単位。そのままでは読みにくいので、確率に直して読む。 オッズ＝上がる確率÷上がらない確率。exp(係数) ＝ 1.66 は「増益だとオッズが1.66倍」という意味。紹介だけでよい。

ロジットモデルのしくみ

P(\text{上がる}) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots)}}

ふつうの回帰直線（点線）は、端のほうで確率が 1 を超えてしまいます（反対側では 0 を下回ることもあります）。
ロジットは S字の曲線なので、どんな値を入れても確率は 0〜1 に収まります。

式は覚えなくてよい。「右辺の中身は回帰と同じ足し算で、それを0〜1に押し込める関数をかぶせている」とだけ言う。 図は EP と size を中央値に固定して、dEP だけを動かしたときの予測確率。横軸は端の少数の会社まで含めた範囲。実際のデータの大部分（約98%）は dEP が -0.12〜0.21 に入っている。 0/1 を lm() で回帰すると（線形確率モデル）、このデータでも予測値が0〜1の外に出る行（社・年）が 19行ある。

連続変数を入れたロジット

logit2 <- glm(up ~ dEP + EP + size, family = binomial, data = df)
summary(logit2)$coefficients |> round(3)

dEP の係数はプラス。増益が大きいほど、株価が上がる確率は高くなります。Pr(>|z|) の 0 は、四捨五入で 0 になるほど小さいという意味です。
確率に直すと、時価総額の10%分の減益（dEP = -0.1）で 46.7% → 変化なしで 58.3% → 10%分の増益（dEP = 0.1）で 69.1%。係数ではなく、確率で語る。

係数の符号と p値の読み方は lm() と同じ。プラスなら「その変数が大きいほど上がる確率が高い」。 ただし係数の大きさは確率ではないので、predict で確率に直して読む。これがロジットを読むときの約束。 期首時価総額の10%分の減益なら上がる確率は約47%、10%分の増益なら約69%。 size の係数はマイナスで有意。重回帰の (4) と同じく、期首に小さかった会社ほど株価が上がる確率が高い。リターンの「大きさ」で見ても「上がったかどうか」で見ても、同じ向きの結果になっている。

今日の裏切り

説明変数をもう1つ足してみます

簿価時価比率（BM） ＝ 自己資本 ÷ 時価総額。割安な株ほど大きい値になります。

df <- df |> mutate(BM = BE / MV)                     # 年末の時価総額で割る

「いつの数字か」を確かめる

年末の時価総額 MV には、今年の株価リターンの結果がすでに入っています。
株価が上がった会社 → MV が大きい → BM が小さい。答えを説明変数に入れていたのです。

問題の核心は、説明変数 BM が被説明変数 R そのものから計算されていること（MV の中に今年の R が入っている）。広くは「ルックアヘッド（先読み）バイアス」の一種として扱われる。 学生から「dEP も今年の利益だから同じでは？」と出たら良い質問。想定解：dEP は R から計算されていないので機械的な結びつきはない。ボール＝ブラウン型の分析は「同じ年に一緒に動くか」を見ており、株価の予測をしているわけではない。 R² が急に上がったのは、R と BM が機械的に結びついていたから。発見ではなく、計算の仕組み。

今日の結合で lag() を使って期首の値を作ったのは、まさにこの事故を防ぐためだった、と回収する。 R² が高いこと・星が多いことは、正しさの証拠にならない。

まとめ

今日おぼえたこと

  • 結合の前に、両方を「1社1年 ＝ 1行」にそろえる。 結合したら行数を確かめる
  • 相関係数は「一緒に動く度合い」。散布図も必ず見る。相関は因果ではない
  • ROE（利益の水準）と株価リターンの相関はほぼ0。株価リターンと一緒に動くのは、利益の水準より利益の変化
  • 重回帰の係数は「他の変数を一定にしたとき」の効果。単回帰の係数は他の変数の効果を混ぜることがある
  • 被説明変数が0/1ならロジットモデル。係数は確率ではないので、確率に直して読む
  • 変数の「時点」を取り違えると、回帰は正反対の結論を出す

left_join(x, y, by = , relationship = ) キーで2つのデータをつなぐ。1対1でなければ止める
