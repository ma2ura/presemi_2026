データフレームの基本

データベースなどから取得したcsvファイルをtidyverseパッケージのread_csv()関数で読み込んで、dfという名前のオブジェクトに代入します。

# tidyverseパッケージを読み込む
pacman::p_load(tidyverse)

# 不要なメッセージを非表示にするために、show_col_types = FALSEを指定していますが、これは必須ではありません。
df <- read_csv("data/03_sales_data.csv", show_col_types = FALSE)

# オブジェクトの型を確認する
class(df)
[1] "spec_tbl_df" "tbl_df"      "tbl"         "data.frame"

class()関数を使うと、オブジェクトの型を確認することができます。 ここではdfの型を確認してみると、"spec_tbl_df"、"tbl_df"、"tbl"、"data.frame"の4つの型が表示されます。 いろんな属性が書いてありますが、data.frameという型になっていることが分かります。

変数へのアクセス

data.frame型のオブジェクトは、変数（列）と観測値（行）からなる表形式のデータを格納するためのオブジェクトです。 変数（列）にアクセスするには、$記号を使って、オブジェクト名の後ろに変数名を書きます。 例えば、dfというデータフレームからsalesという変数（列）を取り出すには、df$salesと書きます。 たくさんのデータが格納されているので、df$salesと書くと、salesという変数の中のすべての観測値が表示されてしまうため、head()関数を使って、最初の6つの観測値だけを表示することができます。

head(df$sales)
[1] 38000000 21000000 13000000 11000000  9500000    32804

売上高salesの平均値を計算してみましょう。 平均値を計算するには、基本関数mean()を使います。

mean(df$sales)
[1] 306895.9

変数の加工

当期純利益net_incomeを売上高salesで割って売上高当期純利益率を計算してprofit_marginという変数に代入し、それをdfに追加してみましょう。 基本関数を使って計算と変数の追加を行うには、次のように書きます。

df$profit_margin <- df$net_income / df$sales

df$を何回も書く必要があるし、なんか見づらいので、tidyverseパッケージの中のdplyrという超便利パッケージのmutate()関数を使って、次のように書くこともできます。

df <- df |> # df に追加する
    mutate(
        profit_margin = net_income / sales # 新しい変数の定義
    )

mutate()

複数の変数を作成、追加することも簡単です。 式と式の間をカンマで区切ることを忘れないようにしましょう。

df <- df |> # df に追加する
    mutate(
        profit_margin = net_income / sales, # 利益率

統計学を使って予想する

たとえば、パン屋さんで1斤400グラムとして販売している食パンを買って、家に持って帰ってから重さを量ったところ、397.5グラムだったとしましょう。この数字をみて、「お店では400グラムの食パンと書いてあったのに、実際は400グラムより少ない！詐欺だ！」となるでしょうか？

お店の人は400グラムの食パンを作ろうとしていますが、できあがった食パンの重さが「400.000000000・・・グラム」になることはなく、誤差が伴うはずです。 そこで、毎日食パンを1つ買って、自宅で重さを量って記録する、ということを10日続けたところ、以下のようなデータになりました。

bread <- c(401.5, 398.5, 395.8, 403.2, 397.9, 399.1, 396.6, 400.5, 393.8, 402.1)
print(bread)
 [1] 401.5 398.5 395.8 403.2 397.9 399.1 396.6 400.5 393.8 402.1

この10個の食パンの平均重量は、

bread |>
    mean() |>
    round(2)
[1] 398.9

食パン10個の平均重量が398.9であったので、客はやはり「お店は400グラムの食パンと言っておきながら、実はもっと小さな食パンを売っている！」と主張します。 この主張はどの程度「もっともらしい」でしょうか？

いま、以下のような状況である。

  • お店では食パンを1斤400グラムとして販売している。
  • しかし食パンが焼き上がるまでにいろんな要因で重量に誤差が生じる
  • 客が買った10個のパンの平均重量は398.9グラムであった

この事実から、お店が実際は400グラムではなく、もっと小さい食パンを製造して400グラムで販売している、とどの程度のもっともらしさで主張できるのかを考えてみます。

母集団

統計学で母集団(population)は、非常に大きなサイズのデータですべてを調べることはできないものです。今の例では、パン屋さんが今まで製造してきたすべての食パンの重さのデータが母集団になります。

母集団をすべて調べることは現実的ではないとき、母集団の平均値や分散である母平均や母分散は誰の知ることのできない未知のパラメータとなります。 しかし、今はこの母平均が400グラムより小さいかどうかを知りたいのです。

標本

母集団を調べることができないので、そこから一部のデータを抽出します。この母集団から取ってきた小さなデータを標本(sample)といいます。この標本の平均や分散である標本平均や標本分散は計算することができます。 この標本平均や標本分散から、母平均や母分散を知るための方法を提供してくれるのが、統計学です。

実際にやってみる。

例えば、パン屋さんが今まで作ってきた食パンが100万個あり、その重さのデータが母集団であるとします。ここでは母平均400グラム、母分散が1の正規分布になっているとします。つまり次のような分布になっているとします。

weight_p <- rnorm(1000000, mean = 400, sd = 5)
hist(weight_p, breaks = 100)

パン屋さんは重さ400グラムの食パンを作ろうとしていますが、完成品の重さには誤差があるので、このような分布になっていますが、母平均は400グラムです。

ここから、10個のパンをランダムに取り出して、その平均重量を量ります。

weight_sample1 <- sample(weight_p, 10)
mean(weight_sample1)
[1] 399.6325

すると、399.63となり、標本平均は400グラムより小さな値（あるいは大きな値）になりました。 しかし、これは偶然集まった10個のパンの重さの平均で、別の10個のパンを抽出すれば別の平均重量が計算されるはずです。

では、母集団である100万個のパンから、10個のパンを取り出して、平均重量を量る、という取り組みを1000回繰り返して、1000個の平均重量を計算してみましょう。

trial <- 1000
result <- numeric(trial)
for (i in 1:trial) {
    x <- sample(weight_p, 10)
    result[i] <- round(mean(x), 2)
}

この1000回の繰り返しによって計算された1000個の平均値がどのような分布になっているのかを見てみましょう。

hist(result, breaks = 100)
