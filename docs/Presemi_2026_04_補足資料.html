データの準備

moodle+Rの「プレゼミ」から03_sales_data.csvをダウンロードして、任意のフォルダに保存します。 ここでは、presemiフォルダの中のdataフォルダに保存したと仮定します。 自分のパソコンで保存した場所に応じて、内容を変更してください。

ファイルの保存場所を示すパス(path)について、「分からない」と思ったら、以下のウェブサイトを参考にしてください。 今更ながらファイルやディレクトリ, ファイルパスって何だろう？ WindowsかMacかで、パスの書き方が異なるので注意です。

Positoronを立ち上げて上部メニューから「ファイル」->「フォルダを開く」でpresemiフォルダを開きます。 一番左のアイコンが並んでいる列の一番上の「Explorer」をクリックし、表れたリストに保存されたファイルが並んでいることを確認します。 これで、Rの作業場所である「ワーキングディレクトリ」がpresemiフォルダに設定されました。

次に機能を拡張するためのパッケージを導入します。 授業では紹介しませんでしたが、とても便利なpacmanパッケージ使います。 このパッケージは、Rのライブラリのインストールと読み込みを自動で行うため、とても便利です。 最初の1回だけ、以下のコードを実行する。

# 最初の1回だけ実行する
install.packages("pacman")

次に、pacmanパッケージを使って、tidyverseパッケージを導入します。 ついでにグラフを美しくできるggthemesとmacの文字化け対策に、showtextを導入します。

pacman::p_load(tidyverse, ggthemes, showtext)  # とにかく最初にtidyverseを読み込む
sysfonts::font_add_google("Noto Sans JP", "noto")
showtext::showtext_auto()

パッケージ名::関数名と書くことで、特定のパッケージの中の関数を指名して使うことができます。 ここではpacmanパッケージの中のp_load()関数を使うために、pacman::p_load()と書いています。 すでに読み込まれているパッケージの中の関数を使う場合は、::は省略できます。

では、分析するためのデータを読み込みます。 授業では基本パッケージread.csv()を使いましたが、より高機能なtidyverseの関数であるread_csv()を使います。

read_csv()は、read.csv()よりも高速にデータを読み込むことができ、また、読み込んだデータの変数の型を自動で判定してくれるなど、便利な機能が備わっています。

データを格納するためのオブジェクト（ここではdf）を作成し、そこに読み込んだデータを格納します。

plot()関数でも、散布図や折れ線グラフなどを描くことができますが、より高機能なグラフを描くためには、ggplot2パッケージを使います。ggplot2は、tidyverseに含まれているので、すでに読み込んでいます。

ggplot2の使い方については、松浦が以前作成した資料https://ma2ura.github.io/R4A/chap11_visualization.htmlを参照してください。

ggplot2でグラフを作成してみます。 グラフ作成で使うデータを指定します。

ggplot(df)

何も表示されていないように見えますが、これでグラフを作成するための下地ができました。 この上に、グラフを書くための情報を追加します。 まずは、グラフを書くための変数をしていするために、aes()関数を使います。aesは、Aestheticの略で、グラフの美的要素を指定するための関数です。 aes()関数の中で、横軸に表示する変数をx、縦軸に表示する変数をyとして指定します。

ggplot(df) + aes(x = sales, y = net_income)

縦軸と横軸が設定されました。 この平面上に、データの点を描くために、geom_point()関数を追加します。 コードを見やすくするために、+の直後で改行して書くことができます。

ggplot(df) + 
  aes(x = sales, y = net_income) + 
  geom_point()

散布図ができあがりました。あとはグラフに装飾を加えていくことで、出版レベルのグラフを作成することができます。 たとえば、以下のようにグラフのラベルやデザインを変更することができます。 作成したグラフを任意のオブジェクトに格納しておくと、あとで再利用することができます。ここではg1というオブジェクトに格納します。

g1 <- ggplot(df) + 
  aes(x = sales/100, y = net_income/100) + 
  geom_point() +
  labs(
    title = "売上高と純利益の関係", # グラフのタイトル
    x = "売上高(億円)", # 横軸のラベル
    y = "純利益(億円)" # 縦軸のラベル
  ) +
  # theme_economist() # windowsの人
  theme_economist(base_family = "noto") # macの人
g1

グラフのデザインを変えてみます。

g2 <- g1 + theme_economist_white() # グラフの背景を白に変更
g2

グラフを並べて表示してみます。

pacman::p_load(patchwork)
g1 / g2 # グラフを上下に並べる。

plotlyパッケージを使うと、インタラクティブなグラフを作成することができます。

pacman::p_load(plotly)
ggplotly(g2)

操作可能なグラフができました。マウスでグラフを拡大したり、グラフの上にカーソルを置くと、データの値が表示されます。

回帰分析

散布図を眺めるだけでも、いろいろなことがわかりますが、より定量的に2つの変数の関係を分析するためには、回帰分析を行います。 回帰分析を行うためには、lm()関数を使います。lm()関数は、線形回帰モデルを作成するための関数です。

回帰モデルとして、 net\_income = \beta_0 + \beta_1 sales + \epsilon を設定します。 lm()関数の中で、net_income ~ salesと書くことで、net_incomeを目的変数、salesを説明変数として回帰分析を行うことができます。 ここでは分析結果をresultというオブジェクトに格納します。

result <- lm(net_income ~ sales, data = df)
result
