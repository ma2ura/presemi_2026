1 はじめに ── 本実習の目的

本ワークシートは、次世代データサイエンスIDE Positron を使って、 以下の3つのデータ分析スキルを実践的に習得するための演習シートです。

  1. 記述統計量の算出：平均値（Mean）と中央値（Median）の乖離、歪んだ分布の把握
  2. データの可視化：ヒストグラム、箱ひげ図、散布図による外れ値の特定
  3. 単回帰分析（OLS）の実行と解釈：回帰係数、統計的有意性（\(p\)値）、決定係数（\(R^2\)）の評価と、外れ値への対処（対数回帰モデル）
ヒントPositronでの操作方法
  • 各コードチャンク（枠）の右上にある 「▶（Run Chunk）」 ボタンを押すか、実行したい行で Cmd + Enter（Mac）または Ctrl + Enter（Windows）を押すと実行できます。
  • 画面上部の 「Render」 ボタンを押すと、全体の実行結果が1枚の美しいHTMLレポートとして出力されます。

3.1 「平均未満」の企業の割合

全体の何％の企業が、平均値よりも小さい売上高でしょうか？

under_mean_pct <- mean(df$sales < mean_s) * 100
cat("平均値未満の企業割合:", round(under_mean_pct, 1), "%\n")
平均値未満の企業割合: 90.6 %

考察メモ：
全500社中、実に 90.6%（453社） の企業が平均値以下です。
上位の超巨大企業が平均値を劇的に引き上げているため、「平均＝標準的な姿」とみなすことはできません。
