今日の問いは「データに直線を引けば、ビジネスの真実がわかるのか？」です。 ビジネスの現場でも「売上と利益の相関関係」「広告費と売上の関係」など、2つのデータの関係を調べたい場面は数多くあります。 直線を引くこと自体は、Rを使えばたった1行で誰でも一瞬でできます。 しかし、その直線の意味を正しく読み解き、隠されたデータの特徴を見抜けるかどうかが、プロと素人の決定的な分かれ道になります。

3分でおさらい：回帰分析の直感と数式

2変数の関係を、最もシンプルな「直線の方程式」で表すのが単回帰モデルです。

Y_i = \beta_0 + \beta_1 X_i + u_i

各パーツの役割

  • Y_i（被説明変数 / 目的変数）：説明したい結果（例：当期純利益）
  • X_i（説明変数 / 独立変数）：原因となる変数（例：売上高）
  • \beta_1（傾き / 回帰係数）：最重要！
    Xが1単位増えたとき、Yが平均何単位増えるか
  • \beta_0（切片）：XがゼロのときのYの予測値
  • u_i（誤差項 / 残差）：直線からの個別のズレ

最小二乗法（OLS: Ordinary Least Squares）

  • 各点と直線のズレ（残差 u_i）の2乗の合計が最も小さくなるように直線を引く！
  • 直線が決まると、次の3大情報が得られます：
    1. 傾きの向きと大きさ（\beta_1）
    2. 統計的有意性（p値 / 星の数）
    3. 決定係数（R^2：説明力）

前回の復習です。 中学で習った直線の式 y = ax + b と全く同じです。 β1が傾き、β0が切片です。 現実の企業は一直線には並ばないので、直線からのズレ ui（誤差）が生じます。 このズレの2乗の合計を最小にするように最もフィットする直線を引く方法が「最小二乗法（OLS）」でした。 この直線を引くことで、①傾き、②偶然ではない確からしさ（p値）、③直線の説明力（R2）の3つが手に入ります。

OLSの直感をイメージで掴む

今日Rで確認する3大情報：

  1. 傾きの向きと大きさ（\beta_1）：売上高が1単位増えると、利益は何単位増えるのか？（マージンは何％か？）
  2. 統計的有意性（p値）：その傾きは、たまたま偶然現れたものか？ それとも確実な関係か？（p < 0.05 で「有意」）
  3. 決定係数（R^2）：引いた直線は、データの散らばりを何％説明できているか？（0〜1の間の値）

この図を思い出してください。 緑色の点が実際の企業データ、赤い線がOLSで引いた回帰直線、青色の縦の点線が「残差（ズレ）」です。 コンピュータはこの残差の2乗和が一番小さくなるベストな直線を一瞬で計算してくれます。 それでは、実際にスライド上のwebRを使って、日本の上場企業500社データで回帰分析を走らせてみましょう！

演習①：lm() 関数で単回帰分析を実行する

Rで線形回帰分析（OLS）を行うには、lm()（Linear Modelの略）関数を使います。

基本構文：lm(被説明変数 ~ 説明変数, data = データフレーム名)
波線 ~（チルダ） は、「左側の変数を、右側の変数で説明する」 という意味です！

lm(net_income ~ sales, data = df) を実行してみてください。 英語と数字がたくさんズラッと出てきましたね。 初めてこの画面を見た学生は、ほぼ100%「うわっ、難しそう…」と圧倒されます。 安心してください。見るべき場所は、たったの「3箇所」だけです！ 次のスライドで、この画面の読み方を世界一わかりやすく解説します。

出力結果の読み方：見るべきは「3箇所」だけ！

さきほどの summary(model1) から、実証分析で絶対に確認すべき重要ポイントを抜き出しました。

① 傾き（sales の Estimate）

  • ビジネスの解釈：
    売上高が1百万円増えると、当期純利益は平均して 0.0451百万円（約4.5万円） 増える！

② p値（星の数） ＆ ③ 決定係数（R^2）

  • p値（Pr(>|t|)）：< 2e-16 ***

このスライドが本日の最重要解説です。 出力のどこを見るか。 まず Coefficients: の sales 行を見てください。 1列目の「Estimate」が傾き β1 です。0.04511とありますね。 売上が100円増えると、利益が4.5円残る。つまりマージンが約4.5%です。 そして一番右の「Pr(>|t|)」がp値です。星が3つついているので、99.9%以上の確信を持って「偶然ではない本物の関係」と言えます。 一番下の「Multiple R-squared」は0.6152。利益の変動の6割以上が売上規模だけで説明できています。 この3つさえ読めれば、回帰分析の基本はマスターです！

外れ値があると、平均値だけでなく、回帰直線までもが激しく歪んでしまうのです！

これこそが、実証分析の初学者が必ずハマる大いなる罠です。 統計ソフトにデータを入れて lm() を実行すれば、誰でも一瞬で直線が引けます。 R2も0.61と高く出ます。 しかし散布図を目で見ると、左下に495社がぎゅうぎゅうに固まっていて、右上のたった数社の超巨大企業が「てこの原理（レバレッジ）」で直線の傾きを強引に支配していたのです。

演習③：実験！ 上位5社を除外したらどうなるか？

この疑いを確かめるために、売上高トップ5社を除外した495社で、もう一度回帰分析を実行してみましょう！

全500社の場合

  • 傾き：0.0451（利益率 4.5%）
  • 決定係数 R^2：0.6152

上位5社を除いた場合（495社）

  • 傾き：0.0602（利益率 6.0% に急上昇！）
  • 決定係数 R^2：0.8682（なんと 87% に激変！）

結果を見てください！ たった5社を除いただけなのに、傾きは4.5%から6.0%へと3割以上も跳ね上がり、決定係数R2は0.61から0.87へと劇的に跳ね上がりました。 つまり、最初の回帰直線は、上位数社の特殊な数字に引っ張られて、残り495社にとっての「本当の関係」を低く見積もっていたのです。 これが「外れ値の影響」です。

なぜこんなことが起きたのか？

超巨大企業特有のビジネス構造

  • 売上高トップ5社（トヨタや三菱商事など）：
    • 売上は十数兆〜数十兆円に達する
    • しかし利益率は 3〜5% 前後に落ち着く巨大ビジネス
  • 一方、残りの495社（中堅〜優良企業）：
    • ニッチトップや高収益企業が多く、平均して利益率 6% 以上を稼ぎ出している
  • 最初の直線は、右上の5社を無理に通ろうとして、495社の傾きを押し下げていた！

実証分析の鉄則

「回帰分析を回す前に、必ず散布図を目で見よ！」
「回帰分析の数値だけを見て満足するな！」

  • 統計ソフトは、どんなに外れ値があっても文句を言わずに計算してしまいます
  • データの「形」を見極め、適切なモデルを選ぶのは、人間の仕事です

なぜこんなことが起きたのでしょうか。 売上高が何十兆円もあるメガ企業は、卸売や重工業などマージンが数％で回るビジネスが多いのです。 一方、中堅の上場企業には高収益な企業がたくさんあります。 最初の直線は、右上の怪獣5社に引っ張られて、全体の姿を見誤っていました。 だからこそ、実証分析では「まず散布図を目で見る」ことが何よりも重要なのです。

第3部：歪みを克服するプロの2大処方箋

解決策：実証会計・経済学の2大アプローチ

では、このような「規模の格差（右に歪んだロングテール分布）」がある企業データに対して、研究者やアナリストはどう立ち向かうのでしょうか？

処方箋①：比率にする（スケーリング）

  • 金額（生データ）のまま比較するのをやめる！
  • 売上高や総資産で割って「比率（率）」に変換する
    • 売上高純利益率 ＝ 当期純利益 \div 売上高
    • ROE（自己資本利益率） ＝ 当期純利益 \div 自己資本
    • ROA（総資産利益率） ＝ 当期純利益 \div 総資産
  • 第2回で学んだ「ROE」は、まさにこの規模の格差を消し去るための知恵だったのです！

処方箋②：対数回帰モデル（Log-Log回帰）

  • 両方の変数に対数（\log）をとって回帰する： \log(\text{net\_income}_i) = \beta_0 + \beta_1 \log(\text{sales}_i) + u_i
  • メリット：外れ値の暴走を抑え、大企業も中堅企業も対等に並べて分析できる！
  • 係数 \beta_1 の解釈（弾力性: Elasticity）：
    「売上高が 1% 増えたとき、当期純利益は何 % 増えるか？」

実証研究者がなぜ「比率」や「対数」を使うのか。 その理由がここにあります。 金額の生データで回帰分析をすると、怪獣のような大企業数社にすべてが引きずられてしまいます。 だから、売上高純利益率やROEのように「比率」にして規模の差を消すか、あるいは「対数」をとって歪みを矯正するのです。 第2回のROEの授業と、第3回の記述統計、そして今回の回帰分析が、ここで一本の線につながりました。

演習④：対数回帰モデルを体験する

黒字企業（利益がプラスの企業）を対象に、両対数回帰（Log-Log回帰）を実際に走らせてみましょう！

  • 傾き \beta_1 \approx 1.02：売上高が 1% 増加すると、当期純利益は約 1.02% 増加する！
  • ほぼ 1.0 に近い値であり、「企業の稼ぐ力は、規模に対してきれいに比例している」 という極めて美しく合理的な経済学的法則が見えてきます。

lm(log(net_income) ~ log(sales), data = df_pos) を実行してみてください。 傾きは 1.02 です。 対数モデルの傾きは「％変化」を表します。 売上が1%増えると、利益も約1.02%増える。 中堅企業から大企業まで、規模に関わらず極めて安定した比例関係が成り立っていることがわかります。

対数散布図を見てみよう！

対数をとると、散布図の見た目はどう変わるでしょうか？ プロットしてみましょう。

グラフを見てください！ さきほどの生データのグラフでは左下に495社が真っ黒に固まっていましたが、対数をとったことで、点が画面全体に均等に散らばり、緑の回帰直線が全体に美しくフィットしています。 特定の巨大企業に直線の傾きがハイジャックされることもありません。 これが、世界中の実証研究者が対数変換を愛用する理由です。

第5部：AIの活用法と「検算」の習慣 ＆ まとめ

AI（ChatGPT / Claude）への頼み方

データ分析でエラーが出たり、コードの書き方が分からなくなったとき、AIは最高のチューターになります。
ただし、「良い頼み方」と「悪い頼み方」 で返ってくるコードの質が天と地ほど変わります。

悪いプロンプト ❌

Rで回帰分析のコードを書いて。

  • 問題点：
    • データ名も変数名も伝えていない
    • 架空の変数を使った動かないコードが返ってくる
    • 往復のやりとりで時間を浪費する

良いプロンプト ⭕

Rの tidyverse を使っています。
データフレーム df には sales（売上高）と net_income（当期純利益）の列があります。
当期純利益を売上高で単回帰するコードと、散布図に回帰直線を引くggplotのコード を教えてください。

  • 成功の3原則：
    ① 道具（R, tidyverse）を言う
    ② データの形（列名・単位）を言う
    ③ 欲しい出力（モデル・図）を言う

実務や卒業論文でAIを活用する際の鉄則です。 単に「回帰分析して」と頼んでも、AIはあなたのデータの中身を知りません。 ①使っている環境・道具、②手元のデータフレーム名と列名、③やりたい分析の3つをセットで伝える。 これだけで、そのままコピーして動く完璧なコードが返ってきます。

検算の型：「動いたコード」が「正しいコード」とは限らない

AIに頼んだコードがエラーなく動いたとしても、「本当に意図したデータで計算されているか」 を必ず自分の目で確認する癖をつけましょう！

AIがやりがちな「静かな間違い」

  • 欠損値（NA）の扱い：
    • 空欄を勝手に「0」で埋めて平均や回帰を計算してしまう
    • 本来除外すべき企業が歪んだ数値として混入する
  • サンプルサイズの脱落：
    • 意図しない条件で企業数が激減しているのに気づかない

覚えて帰る検算の1行（5秒で完了）

検算の極意：「結果の数字」を見る前に、「何社のデータを使って計算したか（サンプル数）」 を必ず確認する！

これはプロの研究者も徹底している習慣です。 AIが出したコードがエラーを出さずに動いたからといって、正しいとは限りません。 欠損値をどう処理したか、何社分のデータで計算したのか。 分析の前後でサンプルサイズを確認する5秒の検算が、あなたのレポートや卒論の信頼性を守ります。

今日のまとめ

  1. 単回帰分析（OLS）の3大情報の読み解き
    • 傾き（\beta_1）：Xが1単位増えたとき、Yが平均何単位増えるか（ビジネスの効率性・マージン）
    • p値（星の数）：関係性が偶然ではない確からしさ（p < 0.05 で統計的に有意）
    • 決定係数（R^2）：データのばらつきを直線が何％説明できているか（0〜1）
  2. 回帰直線と外れ値の罠（今日の裏切り）
    • 機械的に lm() を実行すると、右上に浮いたたった数社の超巨大企業に直線の傾きがハイジャックされる（レバレッジ・ポイント）
    • 「回帰分析を回す前に、必ず散布図を目で見る！」
  3. 歪んだデータを手懐ける2大処方箋
    • 比率化（スケーリング）：売上高利益率、ROE、ROAで規模の差を消す
    • 対数回帰モデル（Log-Log）：\log をとることで外れ値を抑え、傾きを「弾力性（%変化）」として解釈する
  4. 財務指標との美しい接続
    • 売上高を総資産で回帰した傾きは、まさに総資産回転率そのものだった！

本日のまとめです。 単回帰分析の出力の読み方、外れ値によるレバレッジ効果、比率化と対数変換、そして総資産回転率との接続。 みなさんは本日、データ分析の初歩から、プロの実証分析のエッセンスまでを一気に駆け抜けました。
